# Películas App

Aplicación web para gestionar películas, directores, géneros, productoras y tipos.

## Estructura del Proyecto

- `backend/`: API REST con Node.js y MongoDB
- `frontend/`: Interfaz de usuario con React.js

## Instalación y Ejecución

### Backend
1. `cd backend`
2. `npm install`
3. `npm start`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm start`

## Tecnologías
- Backend: Node.js, Express, MongoDB, Mongoose
- Frontend: React.js, Axios, React Router, Bootstrap, SweetAlert2
